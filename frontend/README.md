# Clínica NutriVida

Frontend desarrollado con React, TypeScript y Vite.

## Requisitos

- Node.js 22 o superior
- npm

## Desarrollo

```bash
npm install
npm run start
```

Vite inicia el frontend en `http://localhost:5173`.

## Build de producción

```bash
npm run build
```

Los archivos optimizados se generan en `dist/`. Para servir ese build localmente:

```bash
npm run preview
```

## Pruebas

```bash
npm test
```
